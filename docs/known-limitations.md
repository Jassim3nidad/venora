# Known Limitations

This register consolidates verified audit findings; it is not an issue tracker
and does not mean an item is accepted for production. Verification means code or
documentation inspection unless runtime evidence is stated.

| Area / priority                | Current behavior and risk                                                                                                                 | Workaround / recommended remediation                                             | Verification / reference                                             |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Debug API / Low                | `/api/debug` is disabled with an empty 404 response; deployment behavior still needs release smoke verification                           | Keep disabled and retain regression/smoke coverage                               | Code audit and unit test; [API inventory](api/endpoint-inventory.md) |
| API rate limiting / High       | No centralized Next.js API limiter; abuse and cost risk                                                                                   | Add trusted-identity/IP-aware limits per sensitive route                         | Code audit; [architecture](architecture.md)                          |
| API envelopes / Medium         | Responses use mixed shapes; clients handle inconsistent errors                                                                            | Adopt versioned shared envelopes incrementally                                   | API audit; [error handling](api/error-handling.md)                   |
| Maya / High                    | Signature scaffolding exists but reconciliation/gateway is incomplete                                                                     | Keep disabled; implement/test full adapter and reconciliation before enablement  | Code audit; [payments](payments.md)                                  |
| Supabase deployment / High     | Live grants, RLS state, and deployed Edge Function/JWT settings were not fully queried                                                    | Verify with authorized CLI/dashboard and negative tests before release           | Repository-only audit; [deployment](deployment.md)                   |
| Venue count / Low              | Remaining-count helper is bounded and unit-tested; browser load-more behavior is not executed                                             | Execute browser interaction coverage                                             | Unit test; browser suite blocked                                     |
| Venue identity / High          | Card identity can differ from linked slug/details                                                                                         | Verify venue ID/slug source before action; remove fallback mismatch              | UI/code audit; design gap analysis                                   |
| Supplier fallback / High       | API fallback data can resemble actionable inventory                                                                                       | Clearly label/block actions on fallback; replace with explicit empty/error state | UI/API audit; supplier feature docs                                  |
| Landmarks / Medium             | Multiple public pages may expose duplicate `main` landmarks                                                                               | Use one page-level main in layout contract                                       | Static/audit evidence; accessibility audit                           |
| Mobile drawers / Medium        | Focus trap/return and Escape behavior is incomplete                                                                                       | Provide alternate navigation; implement/test dialog keyboard contract            | Design audit; accessibility requirements                             |
| Supplier crop dialog / High    | Unnamed controls and pointer-only positioning                                                                                             | Use labeled keyboard-operable controls and announce crop state                   | Design audit; accessibility audit                                    |
| Desktop Help / Low             | Control may be dead although `/help` exists                                                                                               | Navigate directly to `/help`; wire control in separate UI fix                    | UI audit                                                             |

| Coordinator / Medium           | Coordinator functionality and runtime role flow are partial                                                                               | Do not promise full workflow; use only verified surfaces                         | Route/flow audit                                                     |
| Admin disputes / Medium        | Disputes screen is a placeholder                                                                                                          | Do not treat as case management; implement separate product scope                | Screen audit                                                         |
| Authenticated flows / High     | Several role and export paths lack complete runtime verification                                                                          | Use dedicated fixtures across tenants/tiers before production                    | Testing gap; [testing](testing.md)                                   |
| Accessibility / High           | Manual assistive-technology checks are incomplete                                                                                         | Run keyboard, screen-reader, zoom, contrast, motion tests                        | Audit gap; design accessibility docs                                 |

| OpenAPI / Low                  | Seven non-blocking Redocly warnings remain                                                                                                | Track and resolve without weakening validation                                   | Validator baseline; [API README](api/README.md)                      |

| Migrations / High              | Upstream `0680` rename and duplicate `071`; numbering is non-contiguous                                                                   | Inspect hosted history/schema and approve forward repair before push/reset       | File audit; [migrations](migrations.md)                              |
| Database types / Medium        | Generated types appear stale relative to later migrations                                                                                 | Repair/rehearse history, regenerate from complete local schema                   | File/migration comparison; [database](database.md)                   |
| Storage validation / High      | Header signature validation and path-level ownership migration exist; malware/polyglot scanning and hosted policy state remain unverified | Add provider scanning if required; execute hosted cross-tenant Storage tests     | Static tests/policy audit; [storage](storage.md)                     |
| Deployment automation / Medium | Repository CI/security/deployment-verification workflows exist; external environment configuration remains incomplete                     | Configure protected GitHub/Vercel values and verify the exact deployed commit    | Workflow/deployment audit; [deployment](deployment.md)               |
| Maps / Medium                  | Public tile/geocoder dependencies can throttle/fail; no Google Maps fallback                                                              | Graceful error/centroid fallback; review provider usage terms                    | Code audit; [architecture](architecture.md)                          |
| AI / Medium                    | OpenRouter-only runtime is locked to `tencent/hy3:free`; live model behavior and deployed Edge configuration remain unverified            | Run controlled provider, grounding, safety, and outage tests                     | Deno/static audit; [AI](ai.md)                                       |

Every remediation needs its own scope, tests, security review, and verification
status update. Do not mark an entry fixed based only on documentation.
