# Known Limitations

This register consolidates verified audit findings; it is not an issue tracker
and does not mean an item is accepted for production. Verification means code or
documentation inspection unless runtime evidence is stated.

| Area / priority              | Current behavior and risk                                                                                                                                                        | Workaround / recommended remediation                                                              | Verification / reference                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Debug API / Low              | `/api/debug` is disabled with an empty 404 response; deployment behavior still needs release smoke verification                                                                  | Keep disabled and retain regression/smoke coverage                                                | Code audit and unit test; [API inventory](api/endpoint-inventory.md)                       |
| API rate limiting / Medium   | The active Next 16 proxy enforces validated per-IP route limits, but counters are isolated per serverless instance and reset on cold start                                       | Add a distributed production limiter without weakening route-specific policies                    | Active proxy unit tests; [architecture](architecture.md)                                   |

| AI event platform / Medium   | Event planning, cost estimation, accredited-supplier matching, and confirmation-gated Concierge actions are integrated; hosted provider/tool/data evidence is pending            | Deploy the exact main commit to protected staging and pass the hosted AI acceptance scenarios     | Source/local validation; [project brief checklist](design/project-brief-role-checklist.md) |

status update. Do not mark an entry fixed based only on documentation.
